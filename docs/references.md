# 📚 Referências Bibliográficas e Metodológicas

As referências listadas abaixo servem como base teórica, técnica e normativa para os processos operacionais estabelecidos pela equipe de engenharia do projeto Gestão RCC[cite: 1, 2]:

1. **Gestão Ágil e Framework Scrum**:
   * SCRUM.ORG. **The Scrum Guide**. Disponível em: <https://scrum.org/resources/scrum-guide>. Acesso em: 2026. *[Utilizado para balizar o ciclo semanal de planejamento, critérios de pronto e retrospectivas do projeto]*[cite: 1, 2].

2. **Gestão da Qualidade e Processos**:
   * ASSOCIAÇÃO BRASILEIRA DE NORMAS TÉCNICAS. **ABNT NBR ISO 9001:2015**: Sistemas de gestão da qualidade – Requisitos. Rio de Janeiro: ABNT, 2015. *[Utilizado como base normativa estrutural para a criação e padronização das seções obrigatórias dos POPs]*[cite: 2].

3. **Versionamento e Fluxo Git**:
   * GITHUB DOCS. **Understanding the GitHub Flow**. Disponível em: <https://docs.github.com>. Acesso em: 2026. *[Referenciado no mapeamento do fluxo curto de ramificações e controle rigoroso de revisões de Pull Requests]*[cite: 2].

4. **Documentação e Engenharia de Processos**:
   * D'AS动力. **Gestão de Processos e Procedimentos Operacionais Padrão (POP)**. São Paulo: Editora Técnica, 2021. *[Utilizado na definição de critérios de sucesso e na estruturação de passos lógicos repetíveis em equipes de tecnologia]*[cite: 2].
