# Sprints do Projeto

Esta pasta organiza os registros de Sprint do Sistema de Gestao RCC, separando claramente o historico reconstruido do desenvolvimento anterior e as Sprints formalmente acompanhadas a partir da retomada em 2026.

As Sprints historicas foram reconstruidas em 2026 a partir do codigo-fonte, documentacao disponivel e historico Git, pois o desenvolvimento inicial do projeto nao possuia registros formais de Sprint. Esses documentos registram a evolucao funcional observavel do sistema sem criar evidencias academicas que nao existiram.

## Observacao de rastreabilidade

Os registros historicos nao substituem Issues, Pull Requests, branches, commits ou evidencias reais. Quando o historico Git permitiu identificar datas, autores ou evolucao de funcionalidades, essas informacoes foram citadas como evidencias. Quando nao havia base suficiente, o registro usa responsavel nao determinado ou equipe do projeto.
